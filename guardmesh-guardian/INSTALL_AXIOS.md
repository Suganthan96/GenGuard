# Install Axios Dependency

Before running the AXL integration, you need to install axios:

```powershell
cd guardmesh-guardian
npm install axios
```

This adds the HTTP client needed for AXL API communication.

After installation, you can run:
- `npm run listener:1` - Start guardian listener 1
- `npm run listener:2` - Start guardian listener 2
- `npm run listener:3` - Start guardian listener 3
- `npm run test:axl` - Run integration test
